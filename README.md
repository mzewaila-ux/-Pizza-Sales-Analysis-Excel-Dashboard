 🍕 Pizza Sales Analysis — Excel Dashboard

An interactive **Microsoft Excel dashboard** for analyzing pizza sales, order volumes, product categories, and purchasing patterns. Built with **Pivot Tables, Pivot Charts, and Slicers** to explore key performance indicators and compare sales across products and time periods.

## 🎯 Project Objectives

- Track overall sales and order performance.
- Compare sales contributions across pizza categories.
- Identify the top five and bottom five pizzas by sales.
- Explore monthly order-volume trends and weekday patterns.
- Enable interactive filtering by pizza size, category, and date.

## 🧰 Tools & Skills

- Microsoft Excel
- Pivot Tables and Pivot Charts
- Slicers and date filtering
- KPI reporting and dashboard design
- Sales analysis and data visualization

## 🎛️ Interactive Filters

The dashboard includes slicers and filters for:

- **Pizza Size** (S, M, L, XL)
- **Pizza Category** (Chicken, Classic, Supreme, Veggie)
- **Order Date / Day**
- **Quarter / Timeline**

**Important:** The displayed screenshot has the pizza-size slicer filtered to **S**, and the size distribution chart shows **S = 100%**. The KPI figures and comparisons shown may therefore represent a filtered view rather than the entire dataset.

## 🚀 How to Use

1. Download `MY Pizza Sales Dashboard.xlsx`.
2. Open the workbook in Microsoft Excel.
3. Navigate to the dashboard worksheet.
4. Use the slicers to select pizza sizes, categories, and dates.
5. Review the KPI cards and charts to explore the filtered results.
6. Clear slicer filters to analyze a broader view of the data.

## 💡 Business Applications

The dashboard can support menu performance reviews, demand-pattern analysis, product prioritization, and reporting. Any operational decisions should consider the applied filters and underlying data coverage.
